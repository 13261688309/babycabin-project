## 逻辑连线

以下仅对应当前总草案网络，**J6 不是商品模块排针顺序**。先取得实际驱动板针序，再做线缆表。H743ZI 的厂家 U9/U10 针号见 [主控核对](H743ZI沉金核心板与连线核对.md)，实物版次/方向仍待确认，FPC1 必须空置。

| 逻辑路径 | TB6612 端子 / 用途 |
|---|---|
| H743 PB10 → U7 → `PWM_OUT` | PWMA；TIM2 CH3，10kHz |
| H743 PA4 → U6 → `IN1_OUT` | AIN1 |
| H743 PA5 → U6 → `IN2_OUT` | AIN2 |
| `M_SW` / `M_IO_3V3` / GND | VM / VCC / GND |
| U7 门控输出 `STBY_OUT` | STBY；禁止直接接 VCC 或旁路门禁 |
| AO1 / AO2 | 电机两端；B 路输出不接，BIN1/BIN2/PWMB 低 |
| H743 PA6 → U5 → `PAN_OUT` | 水平舵机信号 |
| H743 PA7 → U5 → `TILT_OUT` | 俯仰舵机信号 |
| `S_SW` / GND | 双舵机供电 / 回流，不由主控 3.3V 供电 |

TB6612 的 STBY=低才是高阻待机；STBY 高时 PWM=低是短路制动，不能把软件零速描述为高阻滑行。整个动作结束会撤销执行器请求；实际关断、余能和停止距离尚未验证。

## 已实现的软件基线

- 双舵机 1000–2000us，初始中位 1500us；PAN 软件 60–120°，TILT 75–105°，每 20ms 最多 1°。初次机械标定先不装舵盘/摄像头，再确认中位及方向。
- 演示电机目标为正负 20% PWM，渐变换向；一次安抚动作最多 10s，APP 云台保持窗口 10s。重复同模式请求不延长安抚截止时间。
- 上电停止、常闭回路/ARM/PG 检查、200ms 软件供电等待、失电锁定和外部看门狗接口保留。**不能把反馈脚直接拉高、短接 ARM 或删掉隔离来让演示跑起来。**
- 原有电脑只读看板、四状态识别、UART 故障清队列和停止优先行为保留；视觉识别不自动启动电机。

电源草案当前假设输入 4.95–5.05V，普通 ±5% 适配器不自动符合。现有 PG 门槛约 4.3–4.6V，**不能保证舵机最低 4.8V**；这属于下一步电源设计缺口，不通过改软件 PG 为恒真来处理。6V 电机方案也不能照搬旧 5–9V 通用输入或 10V 级 OVLO 当作已匹配保护。
